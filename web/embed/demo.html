Roadie Labs Embed Widget

Add a Roadie Labs race rating badge to your site. Compact, lightweight, and self-contained.

Quick Start

Paste this where you want the badge to appear:

<div class="rl-embed" data-slug="letape-du-tour"></div>
<script src="https://roadielabs.com/embed/rl-embed.js" async></script>

Change data-slug to any race slug from the race database.

Multiple Badges

Include the script once, add as many badges as you want:

<div class="rl-embed" data-slug="letape-du-tour"></div>
<div class="rl-embed" data-slug="maratona-dles-dolomites"></div>
<div class="rl-embed" data-slug="la-marmotte"></div>
<script src="https://roadielabs.com/embed/rl-embed.js" async></script>

Live Examples

How It Works

  • The script loads a compact JSON file (~15KB) with all 328 race ratings
  • Each badge is rendered client-side with race name, tier, score, location, and date
  • Clicking the badge links to the full race profile on Roadie Labs
  • No dependencies, no cookies, no tracking (GA4 event only on roadielabs.com)
  • Styles are scoped to .rl-embed-card and won't affect your site

Available Slugs

Find any race slug at https://roadielabs.com/gravel-races/. The slug is the last part of the race profile URL.
